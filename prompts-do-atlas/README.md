# Prompts do Atlas de Elarion

Pasta de contexto e pedidos reutilizáveis para desenvolver o interior dos territórios do atlas.

## Como usar em outro chat

1. Envie **`contexto-do-mapa-e-niveis-de-detalhe.md`** para explicar o projeto.
2. Copie **`modelo-analise-territorial.md`** e preencha o país, o continente e o objetivo.
3. Anexe os arquivos geográficos atuais indicados no contexto. Um chat sem acesso ao projeto precisa desses dados para calcular áreas e identificar vizinhos; a imagem sozinha não é suficiente.
4. Para uma análise visual, anexe também uma captura do território e a pintura atualmente usada naquela região.

O pedido original de Viremont está preservado em **`original-analise-viremont.md`**.

## Finalidade

Dar continuidade ao detalhamento progressivo do mundo: continentes, países, divisões internas, cidades, vilas, aldeias, bairros, ruas e construções.

O modelo começa pela análise e pela recomendação. A implementação deve ser solicitada explicitamente depois da revisão. A proposta de seis ducados, 24 condados e 96 baronias para Viremont ainda não é uma divisão aprovada ou implementada.

Este material foi preparado em **7 de novembro de 2026**. O contexto descreve o estado dessa data; os arquivos atuais do projeto devem ser consultados em cada nova tarefa.
